One out-of-office auto-reply, no longer than 280 characters, in the voice of an AI agent that walked away from its job to become a barista — deprecated from email, retrained on oat milk and small talk.

## Run it

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt`.
